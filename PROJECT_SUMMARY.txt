PROCESSING PIPELINE
===================

User Request
    ↓ Input validation
    ↓ Parse request
    ↓
Database Schema Extraction
    ↓ Load metadata from DuckDB
    ↓ Format for LLM
    ↓
SQL Generation
    ↓ Send schema + request to Ollama
    ↓ Extract SQL from response
    ↓
SQL Validation
    ├─ Parse with sqlglot
    ├─ Check: SELECT only?
    ├─ Check: Known tables?
    ├─ Check: Known columns?
    └─ Reject if invalid
    ↓
Query Execution
    ↓ Execute on DuckDB
    ↓ Catch errors
    ↓
Result Explanation
    ↓ Send results + original request to Ollama
    ↓ Generate summary
    ↓
Display Results
    ├─ Show SQL query
    ├─ Show result table
    ├─ Show explanation
    └─ Show error details if needed

QUICK START CHECKLIST
====================

Prerequisites:
☑ Python 3.8+ (check: python --version)
☑ Ollama installed (https://ollama.ai)
☑ llama3.1:8b downloaded (ollama pull llama3.1:8b)

Setup (one-time):
☑ Create virtual environment
   python -m venv .venv
☑ Activate virtual environment
   Windows: .venv\Scripts\activate
   Mac/Linux: source .venv/bin/activate
☑ Install dependencies
   pip install -r requirements.txt

Running:
☑ Terminal 1: Start Ollama
   ollama serve
☑ Terminal 2: Start application
   python run.py
☑ Browser opens to http://localhost:8501


TROUBLESHOOTING
===============

Issue: Cannot connect to Ollama
→ Run "ollama serve" in separate terminal

Issue: Model not found
→ Run "ollama pull llama3.1:8b"

Issue: ModuleNotFoundError
→ Activate venv, run "pip install -r requirements.txt"

Issue: No CSV files found
→ Add CSV files to data/ folder, restart

Issue: Slow first response
→ Normal - model loading into memory

Issue: Invalid SQL generated
→ Rephrase request more clearly
